
- Inicializar un nuevo repositorio
```
git init
```
```
git add .
```
```
Git commit -m "Proyecto base Nest"
```
- Subir a GitHub
- Requisitos 1: (crear una cuenta en github)
- Requisito 2: Crear un nuevo repositorio
- Asociar git local con el remoto:
```
git remote add origin git@github.com:LeoB0T/backend-nest-inventarios.git
```
- Subir los cambios al repositorio remoto (github)
```
git push origin master
git push origin develop
```
-Listar las ramas:
```
git branch
```
